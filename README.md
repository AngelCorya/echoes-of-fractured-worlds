# Echoes of Fractured Worlds

Official web hub for **Echoes of Fractured Worlds** by **Angel Corya**.

The site is intentionally **novel-first**: the book is the narrative core, while the interactive Nine Rune Codex, original soundtrack, visual development and video game expand the same canon.

## Current focus
- Novel: final publication preparation
- Lore: interactive Nine Rune Codex and dimensional archive
- Soundtrack: original music in development
- Game: 2D vertical slice in active development

Live site: https://angelcorya.github.io/echoes-of-fractured-worlds/
